# Планировщик комнаты

Веб-приложение на Django для расстановки мебели в комнате. План рисуется в браузере: мебель можно перетаскивать, поворачивать, менять размеры, копировать и удалять, а расстояния до стен и соседних предметов видны сразу. Планировка хранится в базе данных, и сервер проверяет, что мебель не выходит за стены комнаты.

Учебный проект: изучаю на нём Django.

## Возможности

- Интерактивный редактор плана комнаты (SVG + JavaScript).
- Хранение комнаты и мебели в базе данных.
- JSON-эндпоинт для загрузки и сохранения плана.
- Серверная проверка: размеры больше нуля, мебель не выходит за стены.
- Сохранение в одной транзакции: план записывается целиком или не записывается вовсе.
- Защита от CSRF при сохранении.
- Управление данными через админку Django.

## Стек

- Python 3, Django
- SQLite
- HTML, CSS, JavaScript без фреймворков

## Установка и запуск

```bash
git clone <адрес репозитория>
cd <папка проекта>

python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Дальше:

1. Открыть админку http://127.0.0.1:8000/admin/ и создать комнату с размерами в сантиметрах.
2. Открыть редактор http://127.0.0.1:8000/rooms/<id комнаты>/.

## Как устроено

### Модели

- `Room` — комната: название и размеры по осям x и y в сантиметрах.
- `Item` — предмет мебели: тип, название, координаты левого верхнего угла и размеры. Флаг `wall` отмечает предметы, которые висят на стене (например, телевизор): они не конфликтуют с мебелью на полу.

Координаты отсчитываются от левой и верхней стены комнаты.

### Адреса

| Адрес | Метод | Что делает |
|---|---|---|
| `/rooms/<id>/` | GET | Страница редактора |
| `/rooms/<id>/plan/` | GET | План комнаты в JSON |
| `/rooms/<id>/plan/` | POST | Сохранить план целиком |
| `/admin/` | | Админка Django |

### Формат плана

```json
{
  "room": {"title": "Спальня", "w": 490, "h": 290},
  "items": [
    {"id": 1, "kind": "bed", "name": "Кровать", "x": 45, "y": 75, "w": 181, "h": 215, "wall": false}
  ]
}
```

При сохранении (POST) передаётся только `items`, без `id`. Сервер заменяет всю мебель комнаты на присланную.

Ответы с ошибкой, статус 400:

- неверный формат запроса: `{"error": "текст"}`;
- предметы не прошли проверку: `{"errors": [{"index": 0, "messages": {"x_coordinate": ["Предмет выходит за правую стену комнаты"]}}]}`, где `index` — номер предмета в присланном списке.
